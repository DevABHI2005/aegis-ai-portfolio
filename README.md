## Overview

**AEGIS AI** is an interactive personal portfolio designed around the concept of a futuristic intelligence system.

Inspired by cinematic command interfaces and AI-powered systems, it combines a dark technical aesthetic with modern web technologies to present my professional profile, technical skills, experience, certifications, and projects.

The portfolio is designed to be more than a conventional resume website. It provides visitors with an immersive way to explore my work and connect with me.

## Live Preview

🌐 **[Explore AEGIS AI](https://aegis-ai-portfolio-five.vercel.app/)**

## Features

- **Futuristic Interface:** Custom dark-themed interface with a JARVIS-inspired visual direction.
- **Interactive Hero Section:** Animated AEGIS core, system indicators, and navigation actions.
- **Responsive Navigation:** Navigation designed for desktop and mobile screens.
- **Professional Profile:** Dedicated sections for background, education, and experience.
- **Technical Skills:** Organized presentation of technical skills and tools.
- **Project Showcase:** Interactive project cards with repository and project links.
- **Certification Vault:** Dedicated section for professional certifications and credentials.
- **Contact Form:** EmailJS-powered contact form for direct communication.
- **Smooth Scrolling:** Lenis-powered scrolling experience.
- **Motion Effects:** Animations and transitions using Framer Motion.
- **Performance Optimization:** Lazy-loaded sections and optimized production build.
- **SEO:** Search engine metadata and social-sharing metadata.
- **Web Analytics:** Vercel Analytics integration for aggregate visitor and page-view statistics.

## Getting Started

Follow these instructions to run AEGIS AI locally.

### Prerequisites

- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/DevABHI2005/aegis-ai-portfolio.git
```

### 2. Navigate to the project

```bash
cd aegis-ai-portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file in the project root:

```env
VITE_EMAILJS_SERVICE_ID=your_service_id
VITE_EMAILJS_TEMPLATE_ID=your_template_id
VITE_EMAILJS_PUBLIC_KEY=your_public_key
```

Replace the placeholder values with your own EmailJS credentials.

**Important:** Never commit your `.env` file or private credentials to GitHub.

### 5. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### 6. Build for production

```bash
npm run build
```

The optimized production files are generated in the `dist/` directory.

## Deployment

AEGIS AI is deployed using **Vercel**.

To deploy your own version:

1. Fork or clone the repository.
2. Import the repository into Vercel.
3. Configure the required EmailJS environment variables.
4. Deploy the application.
5. Access your live website through your Vercel deployment URL.

Vercel Analytics can be enabled to monitor aggregate website traffic.
